# Agent Bucko

Bucko lives inside a game I'm building. I can ask it to change the world, and it looks around, moves through the scene, places objects, and tweaks the shaders while the game keeps running.

This is my entry for the NVIDIA Paris Claw Agent Challenge. The repo is just the page for the demo.
