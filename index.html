Agent Bucko

NVIDIA Paris Claw Agent Challenge · 2026

An agent inside the game.

Describe what you want to change in the world. The agent sees the scene through its own eyes, moves through it, places objects, and changes its appearance while the game keeps running.

Built into a custom C/C++ game engine, the agent turns a request into a sequence of actions. It calls game tools, reads and edits shader files, reloads the shaders, and takes screenshots through its own view to inspect the result. Each tool returns its outcome before the agent decides what to do next.

The goal is to make world building more direct: describe a scene, then let an agent carry out the work in the game itself while not hindering traditional editor workflows in any way. The agent is purely an addition

Now that it's built, I can further evaluate for a possible in-game interactive NPC/Companion, which presents its own challenges.
